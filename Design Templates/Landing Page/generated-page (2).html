1. Authentication System

Priority: High Est: 3 days

User Story (US-101)

As a new user, I want to sign up via magic link so that I don't have to remember a password.

Acceptance Criteria

  • User enters email address in input field.
  • System validates email format using Zod.
  • Rate limiting: Max 3 requests per minute per IP.
  • Email contains 6-digit expiring token (15 mins).
